A program that writes one funny line to `/output/entry.txt` — a one-line office joke for the laugh-off. An entry for [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) on make.fun.

## The line

> My out-of-office reply has a better work-life balance than I do.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (64 characters, within the 1–199 gate) and nothing else.

- `main.py` — the entry program: writes the line to `entry.txt`.
